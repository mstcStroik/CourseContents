Zoo 1.1, Part 3: Web Actions and Object Collaboration

ASP.NET Core web app version

In this part, you will make the zoo objects collaborate when a guest visits the booth. The browser button replaces the original WPF button click, but the object-oriented behavior remains the focus.

Topics Covered

  • Razor Page form posts
  • PageModel handler methods
  • Method calls and return values
  • Sequence diagrams
  • Object responsibility
  • Validation instead of crash-based checks
  • Encapsulation through business methods

OOP reminder: Ask the object that owns the data to do the work. Money changes belong near Wallet. Inventory changes belong near Booth. Admission belongs near Zoo.

1. Add the Admit Guest Web Action

The original assignment used a WPF button named admitGuestButton. In this web version, use a Razor Page form that posts to a PageModel handler.

  1. Open Pages/Index.cshtml.
  2. Add a form with a submit button for admitting a demo guest.
  3. Use a page handler such as OnPostAdmitDemoGuest in Pages/Index.cshtml.cs.
<form method="post" asp-page-handler="AdmitDemoGuest">
    <button type="submit">Admit guest</button>
</form>

Check Your Work

  • The page redirects or reloads after the post.
  • The app still builds and runs.

4. Add Safe Method Details

The method stubs now need real rules. The booth should protect its own sale rules.

  1. In Booth.SellTicket, check whether the payment is enough to buy a ticket.
  2. Only find and remove a ticket if the payment is sufficient.
  3. If a ticket is found, add the payment to the booth's money balance.
  4. In Ticket.Redeem, mark the ticket as redeemed.

Encapsulation check: The code outside Booth should not remove tickets from the booth's list directly. It should ask the booth to sell a ticket.

Check Your Work

  • The booth gains the ticket price after a successful sale.
  • The guest loses the ticket price after a successful sale.
  • The ticket is redeemed before or during admission, as directed by your instructor.
  • Changing the ticket price in one place changes the behavior everywhere it should.

Rules
